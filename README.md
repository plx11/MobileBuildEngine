# MobileBuildEngine

MobileBuildEngine 是一個高效、原生的 Android 編譯引擎，專為在 Android 設備沙箱環境內執行自動化 APK 構建而設計。它允許開發者透過簡單的 UI 介面輸入專案來源（本地路徑或 GitHub 倉庫），實現「一鍵編譯」。

## 核心功能

- **一鍵式編譯流程**: 支援輸入專案路徑，自動化完成資源編譯、DEX 轉換、打包與簽名。
- **實時監控**: 內建進度條與實時編譯日誌顯示，讓編譯過程透明可視。
- **隔離執行環境**: 每次編譯任務均會在獨立的工作空間執行，確保多工間互不干擾。
- **高魯棒性**: 具備網絡下載重試機制、二進位檔案完整性自檢與異常自動恢復處理。

## 技術架構

- **Kotlin 編譯管線**: 基於 `com.mobilebuildengine.app.core` 的模組化架構。
- **原生工具鏈**: 高效調度 `aapt2`, `d8`, `r8`, `apksigner`, `zipalign`。
- **UI 層**: 採用標準 Android View 實現 MVVM 交互模式。
- **依賴管理**: 內建 Maven 倉庫遞迴解析與緩存下載機制。

## 使用說明

1. **配置環境**: 確保 `assets/binaries` 目錄下包含正確版本的原生工具二進位檔。
2. **輸入來源**: 在 App 主介面輸入本地 Android 專案路徑。
3. **執行編譯**: 點擊「一鍵編譯」，系統將自動執行：
   - 工具鏈完整性校驗。
   - 依賴項解析與自動下載。
   - 資源編譯與 DEX 生成。
   - APK 簽名打包。
4. **結果顯示**: 編譯完成後，日誌將顯示產出物的存放路徑。

## 開發者指南

- **新增編譯步驟**: 在 `BuildEngineController` 中定義新的處理邏輯，並在 `WorkspaceManager` 中管理臨時資源。
- **錯誤診斷**: 核心模組會透過 `BuildLogger` 介面即時回傳狀態與錯誤碼。
